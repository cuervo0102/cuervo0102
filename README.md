<b>🏗️ Fabrilec — Tender & Delivery Intelligence</b> <i>(End-of-year internship project)</i>
<p>An AI platform that analyzes real Moroccan public electrical-sector tenders to help an infrastructure company prepare submissions faster — built from scratch with no company-provided data.</p>

<ul>
<li>🍡 Multi-format document extraction (PDF/OCR, DOCX, XLSX) → Postgres → dbt models</li>
<li>🍡 Hybrid retrieval (semantic + BM25 via Reciprocal Rank Fusion) — boosted precision from 35.7% to 85.7%</li>
<li>🍡 Local LLM agent (Ollama / Llama 3.1) with tool-calling for document search & exact lookups</li>
<li>🍡 Orchestration with Airflow, vector search with Chroma</li>
</ul>

<b>📞 Optiva — AI Sales Call Classification</b>
<p>A lead-qualification system that classifies sales calls end-to-end.</p>

<ul>
<li>🍬 Built with Django, Faster-Whisper (transcription), and XGBoost (classification)</li>
<li>🍬 Pure ML pipeline (TF-IDF + TruncatedSVD + positional features), ~77% accuracy / 0.77 F1</li>
<li>🍬 Async processing with Celery + RabbitMQ</li>
</ul>
